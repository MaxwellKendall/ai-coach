## 12-week probe: The author: 3 days, gym, build week

Logged like a person: about one session in four skipped, and every third week the main lifts' last set a rep short at RPE 9.5.

- **base**: Volume and technique: build squat and bench work capacity, with rowing and pulling for upper-back balance. Main lifts: Back Squat, Bench Press, Bent Over Barbell Row, Pull-up, 8 reps; the rest 12.
