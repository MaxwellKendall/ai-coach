## Cues
- Forearms on the floor, elbows under shoulders. Toes tucked.
- Body forms a straight line from head to heels — do not let hips sag or pike up.
- Squeeze glutes and abs simultaneously. Breathe normally.
- If form breaks before the target duration, stop and rest — do not grind through bad reps.

## Programming Notes
Use for core work in a full-body session when time is limited. Duration-based: build from
20–30 sec holds toward 60 sec. Once 3 × 60 sec is easy, progress to ab-wheel rollout or
dead bug for greater anti-extension challenge. One plank set = one core set in session logs.
Carries and unilateral work (split squat, single-arm row) also accumulate core volume
indirectly — count those in their primary pattern only.

## Warm-up Protocol
No specific warm-up needed. Can be placed at the end of any session or between compound sets
as active rest.
